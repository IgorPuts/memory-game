  # 🧠 Memory Game

Классическая игра на поиск пар: игрок открывает карточки и запоминает их
расположение, чтобы найти все совпадения за наименьшее число ходов.

Приложение написано на чистом JavaScript без сторонних библиотек и фреймворков.
Вся разметка создаётся динамически через `document.createElement`.

---

## 📖 Описание игры

На игровом поле расположены **16 карточек** — это **8 пар** одинаковых
изображений (эмодзи), перемешанных в случайном порядке. Все карточки лежат
рубашкой вверх.

**Правила:**
1. Игрок открывает одну карточку, затем вторую.
2. Если изображения совпали — обе карточки остаются открытыми, счётчик
   найденных пар увеличивается на 1.
3. Если изображения различаются — обе карточки остаются видимыми примерно
   секунду, затем закрываются. Пока пара открыта, выбрать другие карточки
   нельзя.
4. Один ход засчитывается при открытии **второй** карточки — независимо от
   того, совпали изображения или нет.
5. Когда найдены все 8 пар, игра завершается, и автоматически открывается
   модальное окно победы с итоговым числом ходов.

Игра начинается автоматически при загрузке страницы и при нажатии кнопки
**«Новая игра»**.

## ✨ Возможности

- 🃏 16 карточек (8 пар эмодзи), случайное перемешивание при каждой игре
- 🔢 Счётчик ходов и найденных пар
- 🏆 Модальное окно победы с итоговым результатом
- 📊 Таблица лидеров с топ‑10 лучшими результатами
- 💾 Сохранение результатов в `localStorage` (доступны после перезагрузки
  страницы и повторного открытия браузера)
- 🔄 Кнопка «Новая игра» — сброс поля и счётчиков без перезагрузки страницы
- ⌨️ Закрытие модальных окон по **Escape**, клику по фону или кнопке
  **«Закрыть»**
- 📱 Адаптивная вёрстка для мобильных устройств
- ♿ Доступность: доступные названия кнопок, блокировка скролла под
  модальными окнами


  ## 🚀 Локальный запуск

Проект не требует установки зависимостей и сборки. Есть два способа запуска.

### Запустить игру по ссылке:


🛠 Технологии
HTML5 — минимальный index.html,

CSS3 — Grid, 3D‑трансформации для переворота карточек, анимации

Vanilla JavaScript (ES6+) — вся игровая логика, работа с DOM через
document.createElement

Web Storage API — localStorage для хранения результатов

Без сторонних библиотек и фреймворков.


🎮 Как играть
Откройте приложение — игра начнётся автоматически.

Кликайте по карточкам, чтобы переворачивать их.

Запоминайте, где какое изображение.

Найдите все 8 пар за минимальное число ходов.

После победы результат автоматически попадёт в таблицу лидеров.

Нажмите «Новая игра», чтобы сыграть ещё раз, или
«Таблица лидеров», чтобы посмотреть лучшие результаты.
